# خطة تنفيذ تعديلات نظام التفتيش والخلع

خطة شاملة لتنفيذ كافة المتطلبات والتعديلات التي طلبها المدير (إضافة حقول الفاز، القاطع، مكونات البناء، صور الفازات، نموذج المخاطر وإرسال الإيميلات، التوقيع الفني، تفاصيل البلاغات، وتحسينات شاشة حركات التفتيش).

## User Review Required

> [!IMPORTANT]
> يرجى مراجعة النقاط التالية قبل البدء بالتنفيذ:
> 1. إرسال الإيميل لـ (حمزة ملكاوي وراوية مروان) سيتم عبر خدمة ربط البريد أو نافذة إرسال بريد إلكتروني مدمجة (`url_launcher` أو خدمة البريد المتاحة).
> 2. توقيع الفني سيكون عبر مربع رسم توقيع إلكتروني (`SignaturePad`) ضمن نموذج التفتيش.

## Proposed Changes

### [Inspection Movement & Meter Removal]
- إضافة حقول: اسم المنتفع الحالي، رقم الهاتف، اختيار الفاز (1 أو 3 فاز)، قدرة القاطع، مكونات البناء.
- إضافة حقول صور الفازات (الفاز الأول، الفاز الثاني، الفاز الثالث، حمل المتر).
- إضافة صور المعاملة السابقة (صورة التلاعب، تقرير الضابطة، نموذج المراجعة).
- إضافة صندوق شروحات العبث الكبير.
- إضافة ميزة التوقيع الفني.
- إضافة حقول: اسم المساعد، اسم السائق، وقوات الضابطة.

### [Risk Model & Email]
- إضافة زر لفتح نموذج المخاطر (بوب أب) يضم الخيارات:
  - تم تركيب عداد بدون مرتجع.
  - تم خلع عداد بدون تركيب عداد بديل.
- إرسال إيميل تلقائي عند الاختيار إلى (حمزة ملكاوي وراوية مروان).

### [Inquiry & Search Enhancements]
- تحديث شاشة البحث (Search Screen) لإظهار حالة العداد (Connected / Disconnected) وحمل الاشتراك حسب الـ Load Profile.
- فصل الأزرار في شاشة البلاغات لتصبح: "إدخال زيارة" و "إدخال معاملة".
- السماح بإدخال عدد الشرطي القيمة `0`.
- إتاحة إدخال أكثر من عملية في تنفيذ تقرير التفتيش.

## Verification Plan

### Manual Verification
